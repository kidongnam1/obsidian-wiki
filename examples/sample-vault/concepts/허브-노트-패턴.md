# 허브 노트 패턴

외부 파일(부속 자원)을 옵시디안 마크다운 노트(지휘 통제실)에서 끌어안아 연관시키는 구조.

## 표준 허브 노트 구조

```yaml
---
created: {{date}} {{time}}
type: hub-note
status: 🟡 진행중
tags: [project, hub]
---
```

### 필수 섹션

1. **📂 연관 외부 자료 (Attachments)** — Excel, PDF, 도면, 한글/워드 문서를 `[[ ]]` 위키링크로 연결
2. **💡 핵심 요약 및 인사이트** — 프로젝트의 핵심 판단과 발견 사항
3. **🔗 상호 연관 노트** — 관련 프로젝트, 개념, 엔티티 교차 참조
4. **🎯 실행 항목 (Action Items)** — 체크박스 기반 할 일 목록
5. **📝 메모 & 회의록** — QuickAdd Capture로 타임라인 형태 자동 추가

## 설계 의도

- 하나의 노트가 프로젝트의 **전체 맥락**을 담는 진입점 역할
- 외부 파일은 첨부(Attachment)로 연결하되, 핵심 내용은 마크다운에 기록
- 검색 시 허브 노트만 찾으면 관련 모든 자료에 도달 가능
