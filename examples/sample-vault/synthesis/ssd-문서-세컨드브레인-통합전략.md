# SSD 문서 + Obsidian 세컨드 브레인 통합 전략

SSD에 흩어져 있는 엑셀, PDF, 워드, 한글 문서와 옵시디안을 결합하여 강력한 세컨드 브레인을 구축하는 로드맵.

## 5단계 구축 로드맵

### 1단계: 구조 설계 — [[para-framework]]

파일을 확장자별이 아닌 목적별(Projects/Areas/Resources/Archive)로 재분류.

### 2단계: 연결 설계 — [[허브-노트-패턴]]

각 프로젝트/영역에 허브 노트를 만들고, 관련 외부 파일을 위키링크로 연결. 허브 노트가 프로젝트의 진입점 역할.

### 3단계: 자동화 — [[quickadd-자동화]]

- `Ctrl+Shift+H` → 허브 노트 즉시 생성
- `Alt+C` → 열지 않고 메모 추가

### 4단계: 시각화 — [[dataview-카드뷰-대시보드]]

Dataview + Minimal 테마 카드 뷰로 전체 프로젝트 현황을 한눈에 파악.

### 5단계: 파일 연관 — [[obsidian-비마크다운-파일-연관]]

PDF 페이지 직접 링크, 전문 검색(Omnisearch + Text Extractor)으로 비마크다운 파일까지 통합 검색.

## 기대 효과

- 흩어진 문서의 **맥락(context)** 복원
- 프로젝트 단위로 모든 관련 자료 1초 접근
- 키보드 단축키로 지식 입력 마찰 최소화
- 시각적 대시보드로 전체 현황 즉시 파악

## 적용 분야 예시

- 충전소 사업 프로젝트
- 물류 관리
- 자산 관리
- 법규/표준 양식 참조
