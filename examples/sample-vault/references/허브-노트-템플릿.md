# 허브 노트 템플릿

QuickAdd Template 기능에서 사용하는 표준 허브 노트 템플릿. `00_System/Templates/T_Hub_Note.md`에 저장하여 사용.

## 템플릿 원본

```markdown
---
created: {{date}} {{time}}
type: hub-note
status: 🟡 진행중
tags: [project, hub]
---

# 📋 {{title}}

> **📌 한 줄 요약:** (프로젝트의 핵심 목적 정의)

---

## 📂 1. 연관 외부 자료 (Attachments)
* **엑셀 데이터:** [[ ]]
* **PDF/도면 문서:** [[ ]]
* **한글/워드 서류:** [[ ]]

---

## 💡 2. 핵심 요약 및 인사이트 (Executive Summary)
* 

---

## 🔗 3. 상호 연관 노트 (Knowledge Network)
* **관련 프로젝트:** [[ ]]

---

## 🎯 4. 실행 항목 (Action Items)
- [ ] 

---
## 📝 메모 & 회의록
```

## 사용법

1. 위 템플릿을 `00_System/Templates/T_Hub_Note.md`에 저장
2. [[quickadd-자동화]]의 Template 설정에서 이 파일 경로 지정
3. `Ctrl+Shift+H` → 제목 입력 → 자동 생성

## 섹션 설명

| 섹션 | 용도 |
|---|---|
| 📂 연관 외부 자료 | PDF, Excel, HWP 등 비마크다운 파일 위키링크 |
| 💡 핵심 요약 | 프로젝트의 핵심 판단과 발견 사항 |
| 🔗 상호 연관 노트 | 관련 프로젝트/개념 교차 참조 |
| 🎯 실행 항목 | 체크박스 기반 할 일 관리 |
| 📝 메모 & 회의록 | QuickAdd Capture 자동 추가 대상 섹션 |
