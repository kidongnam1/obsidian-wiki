# Obsidian 비마크다운 파일 연관

원리: 옵시디안을 '지휘본부', 외부 문서들을 '부속 자원'으로 취급. 비마크다운 파일은 원본 그대로 연결되거나, 플러그인으로 마크다운 변환되어 통합된다.

## 1. 기본 기능 (추가 설치 없이 즉시 가능)

### PDF

- `[[문서명.pdf]]` — 파일 링크
- `[[문서명.pdf#page=5]]` — 특정 페이지 직접 링크
- 내장 뷰어로 Obsidian 안에서 즉시 열람 가능
- PDF 내부 특정 구절을 드래그하여 마크다운 노트로 직접 인용 링크 생성 가능

### Excel / Word

- 볼트 내 포함 시 클릭 한 번으로 로컬 프로그램(엑셀/워드)에서 실행
- `[[보고서.xlsx]]` 형태로 위키링크 연결
- 마크다운 노트에서 "이 수치는 [[보고서.xlsx]]의 3번 시트 참고" 형태로 맥락 연결

### HWP (한글)

- 동일하게 `[[문서.hwp]]`로 링크
- 클릭 시 한컴오피스에서 실행

## 2. 추천 플러그인 (상호연관 극대화)

| 대상 | 플러그인 | 핵심 기능 |
|---|---|---|
| PDF | **PDF++** | PDF 내 하이라이트(색칠)를 마크다운 메모와 실시간 양방향 연결. 주석 ↔ 노트 동기화 |
| PDF/Excel/Word | **Omnisearch + Text Extractor** | PDF, 엑셀, 워드, 이미지 내부 텍스트를 Obsidian 검색창에서 통합 검색 |
| Excel | **CSV Editor** | 엑셀 데이터를 CSV로 저장 시 Obsidian 내에서 인터랙티브 표로 편집 |
| Excel | **Dataview** | CSV/프론트매터 데이터를 쿼리로 불러와 동적 테이블·리스트 생성 |
| Word | **Pandoc** | 워드 문서를 마크다운으로 자동 변환하여 Obsidian 노트로 완전 통합 |

### 플러그인 조합 시너지

- **Omnisearch + Text Extractor**: obsidian-wiki의 `wiki-query`가 마크다운 페이지를 검색한다면, 이 조합은 원본 PDF/Excel 내부 텍스트까지 보완 검색
- **PDF++**: obsidian-wiki에 없는 기능 — PDF 하이라이트와 마크다운 간 양방향 실시간 연결
- **Pandoc**: 워드 파일을 마크다운으로 변환하면 obsidian-wiki가 인제스트할 수 있는 형태가 됨

## 3. 첨부 파일 자동 수거

옵시디안 설정:
- **파일 및 링크** → **새 첨부 파일의 기본 위치** → `01_Attachments` 폴더 지정
- 드래그&드롭하는 모든 외부 파일이 해당 폴더로 자동 수거
- 볼트 루트가 깨끗하게 유지됨

## 4. Best Practice: 허브 노트 패턴

외부 파일을 보관소에 넣은 뒤, 마크다운 '[[허브-노트-패턴|허브 노트]]'를 만들어 중심점으로 활용:

1. `2026_물류창고_안전점검.md` 마크다운 노트 생성
2. 노트 안에 `[[안전점검_원본.xlsx]]`, `[[법률검토.pdf]]` 첨부
3. 핵심 요약, 인사이트, 실행 항목 기록
4. 관련 사업 노트와 `[[위키링크]]` 연결

→ 원본 데이터 보존 + 그래프 뷰 지식 네트워크를 동시에 활용
